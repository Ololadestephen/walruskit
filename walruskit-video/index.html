RECOVERKIT

Introducing WalrusKit.

Programmable recovery for encrypted Walrus data on Sui.

The problem

Walrus stores blobs. Apps still need recovery infrastructure.

problem.scan 
detecting missing infra...
encryption       manual
walrus upload    custom
sui policy       custom
tatum reads      custom
recovery state   custom

result: every team rebuilds the same recovery stack
The missing layer

Encrypted data needs programmable recovery.

Who can recover it, when recovery can start, and what conditions must pass.

The kit

WalrusKit turns that flow into reusable developer infrastructure.

StoreCiphertext on Walrus
AnchorRecovery policy on Sui
ReadCapsule state through Tatum RPC
ExposeSDK, CLI, UI, MCP, and Agent Kit

Architecture

Encrypt locally. Store on Walrus. Enforce on Sui. Read through Tatum.

01

App runtime

Plaintext exists only before encryption.

02

Walrus

Ciphertext blob is stored decentrally.

03

Sui capsule

Blob ID, hash, size, and recovery policy are anchored.

04

Tatum RPC

Apps read package and capsule state.

05

Verifier

Downloaded bytes are checked before recovery.

Recovery policy

A Sui Move capsule controls when recovery is allowed.

Owner heartbeat Beneficiary request Guardian threshold Final delay Owner cancellation

Agent Kit + MCP

Agents can explain recovery state without seeing secrets.

agent.inspect(capsule) 
owner inactive        yes
recovery requested   yes
guardian approvals   1 / 2
final delay          waiting

agent says:
"Not yet. One more guardian approval is needed."
Safe by design

The agent prepares actions. The wallet signs.

No plaintext secrets, no private keys, no bypassing Sui policy.
