# WalrusKit Quickstart

1. Encrypt locally with `@walruskit/crypto`.
2. Upload ciphertext to Walrus with `@walruskit/walrus`.
3. Anchor the blob ID, hash, size, and recovery rule on Sui.
4. Read capsule state through `@walruskit/tatum`.
5. Verify the Walrus blob with `@walruskit/verifier` before decrypting.
